This additive mode belongs to the existing `shroud_frontier` native owner:

```sh
python -B -m tools.procedural_drawing_oracle.shroud_frontier --fire --write
python -B -m tools.procedural_drawing_oracle.shroud_frontier --fire --check
```

The default stationary and `--moving` modes retain their existing payloads.

The selected consumer is the existing simulation vision/fire caller chain.

world, Cell constructors and source AMCV admission are reused. Cell120,30 has
physical GoldSt tile/sub/height and actual native TMP slope/land. After the

The mode executes this sequence cold, then repeats it warm without resetting
knowledge or caches. It invokes the original Logic modulo gate at component
frames119,120,240. Frame119 must not sweep. Both120/240 execute the complete
original578100 and578290 iterator; notification5865F0 is observed at its true
entry with the actual Cell/frame/fresh/current-viewer arguments. No callback
is supplied, and no occupied Tag consequence is claimed.

The existing raster crop alone cannot support a full allocated sweep: the
iterator would terminate at its first missing Cell. This mode additionally
enrolls **every physical authored GoldSt Cell** through original47BBF0 and

outside the original crop are not asserted. Each sweep pass must visit every
authored Cell exactly once; unexpected or missing receivers fail generation.
No fake iterator or shortened map Size hides missing coverage.

## Compact consumed state

`state_columns` names compact actual native state rows. Input source identities,
physical fire tuple, native XYZ, map/flags/frames, startup and enrollment bounds
remain separate from observations. `initial_nonconstructor_cells` retains only
state changed by the native prefix relative to the original constructed Cells.
Each stage retains only deltas from its preceding stage plus the source Cell.

`map_calls` and `leaf_receivers` retain the actual calls/ordered receiver Cells.
Each `borders` entry retains native caller/XYZ/inner/radius/skip and ordered
`[x,y,old_ground_frame,new_ground_frame,old_dirty,new_dirty]` rows. Full sweep
passes retain counts, first/last receiver and a hash of their actual ordered
coordinates, rather than a bulk16810-Cell replay. Notifications retain actual
phase/pass/Cell/fresh/viewer and stored ground frame. The cold call must change
stored120 before the sweep; a warm-only no-change control is insufficient.

Full before/after states of the three inherited RNG streams and request absence
are checked around measured work. Selected original body bytes are compared
before and after. No border, leaf, sweep or notification result is supplied.

## Scope

This is the Map/border/sweep component, not a full FireAt or Spawner constructor
execution. Normal versus Spawner early-exit predicates remain instruction-level
caller evidence and production fire tests. In particular, Spawner's independent
border can run without the radius3 reveal, whereas normal fire's outer border
shares its later victim/RevealOnFire gates. This tool does not fabricate a host
predicate test for those branches.

The stored ground frame is simulation state: later578100 tests its prior value
when deciding synchronous5865F0 notifications. Full-frame A reconstruction can
replace native tactical dirty queues, but cannot replace that earlier stored
value. These controls preserve the existing single geometry/cache/notification
owners and do not introduce rendering, parser or numeric implementations.
