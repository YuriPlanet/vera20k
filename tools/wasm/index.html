Where is my game folder?

  • Pick the Yuri’s Revenge install folder: the one that contains ra2md.mix and ra2.mix.
  • Steam / EA app installs usually live under Command and Conquer Red Alert II in the library folder.
  • Choosing a parent folder is fine — the game folder inside it is found automatically.
  • Nothing is uploaded. Game files are read into memory and must be chosen again after reloading.
  • Needs WebGPU: a recent Chrome or Edge works best. Large installs need plenty of memory.

Settings and saves are stored in this browser for this site.
