# SpySat reference, admission and independent cue components

The opt-in `unit_voice_playback.py --spy-sat-audio` profile reuses the existing
joined input/runtime fixtures, `VoiceHistory`, `NativeAudioPlatform` and
`NativePcmObserver`. It does not execute a complete native House update or
Map reveal/reshroud. Historical GI, feedback, slave-miner and radar payloads
retain their existing schemas and preparation.

The generated sidecar records the reproduction command, not the executable's
hash, source hashes or validation results.

## Retail inputs and original readers

The common descriptor-driven pair observer executes original Rules constructor
`665650` and the AudioVisual slice **66A4EF inclusive to 66A582 exclusive**.
That slice includes the retained `+1B8` store, both exact-case string reads,
native `7514D0` lookups and the `+224` store at `66A57C`. Its entry supplies
ESI=Rules, EDI=INI, EAX=retained1B8 and ESP=SP. Its explicit stop retains the
next read's scheduled `push 128`: ESP=SP−4 and [SP−4]=128. This interior region
is not presented as a whole AudioVisual call.

`SpySatActivationSound` and `SpySatDeactivationSound` retain constructor-derived
defaults when missing, empty or unresolved. Controls observe cold missing and
unknown, stock references, subsequent missing/empty/unknown, name/key/section
case, 127/128/129-byte capacity and accepted replacement followed by unknown.
The runtime cold-unbound history takes its slots from the actual cold reader
result.

The physical AudioVisual values select SOUNDMD sections `SpyUplinkOn` and
`SpyUplinkOff`. Original `7510D0` registers those physical sections and Defaults;
original `7514D0` resolves the references. SoundList keys are not runtime Voc
indices. Original `4011C0`, its sort/lookup and physical IDX/BAG determine
sample admission and identity. The payload records the native Sound fields and
sample indices.

Original `45DD90` constructs the GASPYSAT type. The existing scalar regions
`45FF53..45FF85` and `5F94D3..5F94F3` read Radar, SpySat and Strength through
RULESMD, optional LANGRULE, MPBattleMD and selected XMP03T4 layers, in order.
Historical joined preparation retains its Hills/E1 prerequisite reads.
Full GASPYSAT type/resource loading, placement and scenario loading are excluded.

## Separate native execution boundaries

Each history supplies an admitted House member with the real native Building
vtable/type pointer, marked/not-limbo/discovered state, unwarped byte and Guard
mission. Queued Selling19 is a declared refusal input; it is not native sale
execution. Local, remote and native-read cold-unbound histories each run five
phases: no provider, gain, same value, loss and reversal.

**Partial admission:** original `508F60` executes its ordered scan, actual
virtual `70C5B0` query and dirty-byte clearing. It stops before the selected
Map CALL at `509064` or `509012`, or reaches the real unchanged-state return.
The observation records the reached PC, caller registers, saved stack, call
bytes, native sites and selected writes. No pending whole-House return is
retained for a later invocation to settle accidentally.

**Independent cue tail:** a separately declared invocation starts at original
`509069` or `509017`. With a new ESP=T, its frame contains saved EDI, ESI, EBP
and RET_MAGIC, and ESI=House. Saved values come from the admission caller inputs.
T is not the unexecuted Map call's hypothetical return stack. The original tail
writes the SpySat latch, checks the local House, loads the native-read Rules
reference and calls `750920` with centered pan, volume and NULL handle. Its
actual return must leave ESP=T+16 and restore the declared saved registers.

No Map callee, result, return or instruction is replaced. Entering `577D90`,
`577AB0` or the selected reveal/reshroud/graphical callbacks fails the component
fixture. This exclusion also applies to the remote history: it does not claim
even a native remote Map early return. House `+240/+241` remain explicit input
priors, not certified Map outputs. Admission and tail metadata state
`map_executed=false`; the tail also states `manufactured_map_return=false`.

## Continuous selected audio history

All three Main, Scenario and MapGen buffers continue from the existing original
seed31 setup without per-phase resets. Complete states use the shared interned
0x3F4-byte representation; exact ranged requests and raw advances are separate
observations. This is uninterrupted selected-component RNG, not whole-world
RNG: intervening Map work is deliberately absent.

The same native audio pool receives the independent tails' actual requests.
Reversal can overlap earlier NULL-handle events. Existing service1033/1034,
the retained worker context, original endpoint and later service own playback
and natural retirement. The fixture fails if the existing bounded worker
sequence cannot finish. It supplies no PCM, RNG, sample-admission or completion
result.

The common PCM projection associates each literal returned callback with the
native backend, event pointer, serial and cached sorted AudioIndex sample
identity. It rejects backend reuse across unrelated lifetimes. Returned byte
counts/digests, terminal drain callbacks and source ranges come from the
existing observer; identity is not inferred from them. Device clocks/status/
cursors are explicit single-thread transport inputs. Hardware concurrency,
device mixing and audible equivalence are excluded.

The base VoiceHistory phase/pool/RNG and playback schemas match the radar
comparison. SpySat admission and independent-tail records are additive. Native
Map/Cell changes, sight/gap processing, construction/sale/dirty writers,
whole-House/frame cadence and paid production are separate evidence obligations.

## Reproduction

Use a flat immutable physical cache containing the selected retail INIs, actual
XMP03T4 map and physical IDX/BAG; its exact membership is recorded by the payload.
The existing radar cache can be read unchanged because this scope needs no new
resource bytes. With the supported executable configured:

```sh
VERA20K_SPY_SAT_AUDIO_INPUTS=/absolute/prepared/extract \
PYTHONDONTWRITEBYTECODE=1 python -m tools.input_oracle.unit_voice_playback \
  --spy-sat-audio --check
```

`VERA20K_SPY_SAT_AUDIO_MAP` defaults to `XMP03T4.MAP` and may select another file
already in that cache. `--write` writes the new default payload and sidecar;
`--write --output /absolute/scratch/reference.json` selects another output.
Run logs and validation receipts stay outside the repository.
