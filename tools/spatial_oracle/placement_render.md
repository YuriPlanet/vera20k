# Ordinary building placement marker and centering

Run `python -m tools.spatial_oracle.bridge_shadow_render --placement --check` with the configured supported retail executable and archives. `--write` regenerates the small corpus and its binary-hash/command sidecar. The existing shared caller module dispatches this mode; `placement_render.py` owns its selected BuildingType/foundation orchestration. Archive extraction, lexical records, allocation, RawFile IO, SHP decoding, palette construction and pixel storage retain their existing owners.

The active route is Tactical draw `6D3D10` call `6D4651` → foundation renderer `6D5030` → Cell marker `47EC90` → `4AED70` → Convert selector `490E50` → rowwalker `437A10` → row leaf `4960A0`. The corpus executes the complete Cell caller and original raster, plus one bounded complete foundation-renderer scene. It supplies sparse live Cell state, current type/proximity, viewport, initialized surface and surrounding visibility. This is not a native map/session bootstrap or paid-factory comparison.

Original startup loads/expands `TEMPERAT.PAL` at `52BC49..52BCBB` before constructing the two basic Converts at `52BE61..52BFCE`. Global `87F6C4` receives the plain `48E740` Convert with physical expanded `PALETTE.PAL` as source, `885780` (expanded TEMPERAT) as destination, RGB565 primary surface, 53 rows and final argument zero. The shared initializer's optional `early_temperat` retains this order only for this mode; its historical defaults remain unchanged. Native `4BBB00` constructs RGB565 rows from the source palette. The selected `0x20600` draw requests brightness 1000 and chooses Convert+D0/vtable `7E55C0`; its row method at vptr+4 is `4960A0`. Nonzero source indices copy the selected translation entry opaquely. Neither A nor old Z participates, and Z remains unchanged. Class Z adjustments are nevertheless recorded from the original caller. No guessed translucency percentage is used.

Original GAPOWR `45DD90` and complete `45FE50` readers execute on expansion RULESMD, Battle mode and GoldSt layers, with fixed ARTMD cache. Foundation tables `45B1C0`, getter `45EC20`, land reader `674000` and ToTile postpass `465CC0` execute. Constructor Adjacent 3 becomes retail 2; WaterBound's missing-key native default converts constructor speed 0 to -1. Naval, PlaceAnywhere, upgrade string, Gate, ToTile, ToOverlay and laser-fence fields remain absent/false for this selected type. These are selected-path exclusions, not declarations that the other branches are unreachable.

The physical GoldSt authored cells identify tile512/sub0/level5 at `(106,34)` and `(106,35)`. Native URBANMD INI reads and original ordinal projection identify RampSmooth base510. The original full lazy TMP loaders read physical `rmpfx03.urb` and the three selected W/E neighbor files (`clat03.urb`, `clat04.urb`, `proad02.urb`); native getters establish ramp slope1/Land0 and neighbor flat slopes. The same raster VM executes complete Recalc `47D2B0` and LAT `47CA80` twice for each selected cell, with physical authored levels, native Rules CliffBack reads (2), sparse type/zone storage and source-derived neighbor publications. All six CliffBack height neighbors are supplied; only W/E neighbor slopes are consumed by LAT. Other supplied neighbor slope fields are unused and are not claimed native-produced. `inputs.map.native_recalc.rows[].output` records the final tile512/sub0/level5/slope1/Land0. These controls establish the selected final producer at that boundary, not complete native terrain registration, map initialization or actual full-map sweep order. The separate production load/placement comparison enrolls actual live final terrain.

LAT is active for this tile. Its selected slope1 W/E checks both see flat and retain tile512. LAT writes only tile identity; it does not write subtile/slope or recursively Recalc. The later slope-zero store `47DB52` belongs to the invalid/sentinel path selected before the valid writer, and is not reached after this valid normal path. Ordinary override -1 preserves level. Physical selected TileSet0043 supplies neither TileAnim nor ShadowCaster overrides; constructor fields retain -1/false and avoid animation/shadow side effects. The repeated selected calls do not claim the full native map bootstrap.

The native occupied foundation list is row-major: `(0,0),(1,0),(0,1),(1,1)`. Rendering `6D5030` independently calculates rectangular bounds and loops X outer/Y inner. The scene records that order and original incoming Cell points. Its native view origin is `[2064,1944]`; production world coordinates use their existing +15 Y convention, so the corresponding camera origin is native view plus `[0,15]`. Retain the shared gameplay foundation-list owner; do not reorder it to match rendering.

Fourteen component rows cover active flat/slope1, pending, no mark, proximity false, all-hidden visibility, signed level bytes 0/5/6/128, clipped/repeated drawing and A/Z independence. Hidden active ordinary cells still draw the invalid marker; they return false. Pending bit4 selects frame1 without active admission. The selected stock active bit2 invalid slope1 uses frame3, whose half-height physical shape differs from the flat red diamond. Flat frames1/2 contain identical decoded pixels; their number difference alone is not a visible defect. `rows.output.runs` and `scenes.output.runs` are lossless original RGB565/Z observations, not decoded host pixels or fitted expectations.

The marker draw path passes no RNG, gameplay timer or detach operation. `4A8BF0`/`4A95A0` own active mark publication/cleanup. `6DA360` only copies the requested packed coordinate. Whole-foundation visibility `4A9070` is a separate local-player, non-editor gate: it visits native type width/height and checks floor-center shroud, with resolved ToTile bypass. Proximity `4A8EB0` visits the surrounding own/allied eligible base ring. Neither is a copy of Cell `47C620`.

Paid ready-object entry, event production/receipt, blocked retry, cancellation, successful placement and detach/expiry remain with the consumed `tools/sidebar_oracle/cameo_order` owner. Failed `HousePlace4FB0E0`→`BuildingUnlimbo440580` restores the saved ready object. Keep that distinction when interpreting a blocked-click test. This corpus does not replace or certify that lifecycle, walls/autofill, upgrades, naval, ToTile placement, arbitrary foundations, other slopes or other draw-flag material arms.

`centering` adds a small non-raster prerequisite comparison after the existing rows and scene, preserving their output and allocation facts. The same VM executes GAREFN constructor `45DD90`, physical RULESMD→Battle→GoldSt Image block `5F92F9..5F9340` and Adjacent block `45FFAF..45FFC7`, fixed ART Foundation block `461225..46125D`, native occupied-table binding `46152C..461547` and getters. Constructor Foundation0/Adjacent3 becomes physical Foundation12 (`4x3`)/Adjacent2. Image remains GAREFN. The complete occupied list contains all12 cells x0..3/y0..2; it comes from `89C900`, separately from the exit-perimeter `89D368` bound at `46156A`. ART Add/RemoveOccupy does not justify substituting a hole in this list. A supplied Building shell with native vptr and the actual type pointer executes ObjectGetFootprint `5F5B90(true)` and returns that same list. This is not a paid GAREFN object or ManualPlace bootstrap.

Full GAREFN ReadINI/resource execution is excluded: exploratory enrollment stopped at the existing prepared RawFile guard for the Bib resource. No resource result is fabricated. Complete `45FE50` instructions write Foundation+EF0 only at `461248/461257`, occupied-pointer+DFC only at `461541` and Adjacent+EB4 only at `45FFC1`; the later reader tail and called visual-loader `45F230` do not replace those selected fields. The retained prerequisite blocks therefore establish centering inputs without claiming the whole type reader, Bib/image resolution or every placement field. Physical source identities remain under `inputs.sources`; the optional LANGRULE absence is the same prerequisite recorded under `inputs.building.langrule_absent`.

`centering.controls` supplies each of the22 native fixed selector values, reading names/values from original `81B9D8`, then executes binding/getter, bounds `4A94F0`, SetActive `4A8BF0` and marker `4A95A0`. Outputs are native observed bounds, offset and the actual marker-entry origin. Bounds comes from max-minus-min of the sentinel list with minimum1; consequently empty `0x0` has observed bounds `[1,1]`, while its type dimensions remain zero. Signed `NEG/MOVSX/CDQ/SUB/SAR` in `4A8CA6..4A8CCF` divides toward zero: 4×3 gives `[-1,-1]`, not a floor-rounded -2; 2×2 gives zero. These selector priors are numeric controls, not claims that a stock type selects every foundation.

`centering.edge_controls` executes the same actual4x3 setter for supplied unsigned packed center words0,1,32767,32768,65535 on both axes. The captured marker origins are decoded as signed16; native word wrapping is retained before map admission, including0→-1 and32768→32767. These are component arithmetic controls, not natural map-coordinate producers or assertions that off-map marks are admitted. All selector names/values come from the executable table, not the Rust table.

`centering.lifecycle` uses the physically read GAREFN list and supplied sparse level0/revealed Cell shells. Original activate at center `[110,33]` marks x109..112/y32..34; move to `[111,34]` unmarks the old origin and marks x110..113/y33..35; clear retires every bit2 mark. `steps[].marker_calls` records native mark/unmark origins directly, rather than calculating them in Python. Move executes original `4A91B0` from entry through the center publication, stopping at `4A943A` before independent proximity/visibility evaluation. Supplied packed coordinates bypass mouse inverse; original `6DA360` still executes. The comparison neither claims admission nor emits a Place event. Existing inverse, paid-event and ready-object lifecycle owners remain authoritative. This selected arithmetic/mark path passes no RNG draw, gameplay timer write or Detach call; its one-time CRT atexit registration remains the existing service seam.
