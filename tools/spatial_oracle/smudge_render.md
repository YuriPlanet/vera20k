# Current-Cell CRATER11 drawing

Run from the checkout with the configured active retail game and Python environment:

```sh
python -B -m tools.spatial_oracle.bridge_shadow_render --smudge --check
```

`--write` explicitly regenerates this mode's JSON/sidecar. The existing default,
`--body`, `--ore`, `--tile` and `--placement` modes retain their defaults. The
sidecar pins the original executable and command, not repository source hashes.
The production consumer is `src/render/smudge_gpu_tests.rs`.

This mode shares `tmp_clear_render`, `PaletteReader`, physical archive/lexical
inputs, original CellConvert/LightConvert, native SHP drawing and the existing
RGB565/A/Z surface and lossless snapshot owners. It contains no renderer, SHP
pixel decoder, palette formula, sight kernel or additional VM implementation.
The original image is unchanged.

`cell_calls` and `draws` retain actual full-Cell projection, four-piece order
and type/shape/material arguments. To isolate this selected production draw
pool, `output.runs` then comes from replaying those **captured original** type
arguments through full6B55F0/SHP on the same VM over the declared background and
A/Z prior. This is the **smudge-only layer**, not full Cell/terrain/frame output.
Each run is `[x,y,length,RGB565,Z]`, omitting only unchanged background/Z pairs.
Prefix hashes preserve actual repeated opaque-call idempotence. No fitted
pixels or Rust projection/material values initialize this native comparison.

The flat uniform-material bound permits the production origin-only composite
policy when its output matches; this does not prove equivalence with different
per-cell lighting, slopes or partial raw-slot clearing. Production uses the
actual AssetManager/atlas/SmudgeGrid/builder/pool/A bind and GPU consumer; the
native fixture does not certify those by itself.

## Lifecycle and residuals

No drawing RNG/timer/detach is introduced; the warmed Main selector state is
unchanged by each caller/replay. The real fatal producer is not RNG-free: its
existing consumed corpus owns selection/ID/request streams, immediate UnInit,
three expiry notifications/deferred destruction and persistence of the four
slots. This drawing corpus does not recertify that whole chronology.

The existing `building_death_anims --joined-stock-smudges` owner now retains a
separate additive seed1 fresh constructor→successful wholeUnlimbo→43F8A6 cleanup
after its real deferred drain. It clears type48 and retains raw data11F; its
House/map/sparse-animation and paid-production exclusions remain explicit. The
drawing mode does not itself rerun that lifecycle. Cell/Convert retirement, full native
map/zone/RNG startup, arbitrary smudge types/formats, nonuniform per-cell light,
cliff ordering and whole Cell480350 remain open. Small invisible color/position
differences follow the project's residual policy; no general visual bug or
whole-function parity follows from a sample.
