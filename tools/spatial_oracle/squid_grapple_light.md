# SQDG copied light, constructor depth and DrawIt entry

Run from the checkout with the existing physical grapple input closure:

```powershell
$env:VERA20K_GAMEMD_EXE = 'C:/your-retail-install/gamemd.exe'
$env:VERA20K_BUILDING_DEATH_ASSETS = 'C:/your-private-inputs/grapple'
python -m tools.spatial_oracle.squid_grapple_light --check
```

The default checks without writes. `--write` deliberately regenerates the
adjacent JSON and sidecar. Import and `--help` execute no native calls or asset
reads. `finish_vectors` guards the contributing native setup/transport sources
before and after generation without publishing source or executable hashes.
The payload retains semantic fields and literal original instruction addresses;
it contains no executable bytes, private paths, heap pointers or retail payload.

The input directory is the existing
[`building_death_anims` grapple closure](building_death_anims_joined.md#squid-grapple-numeric-component):
physical RULESMD, optional LANGRULE, MPBattleMD, ARTMD, SOUNDMD, Hills.mmx and its
unchanged inner Hills.map, the Construction/Engineer/death SHPs, SQDG/WAKE/H2O
SHPS and audio IDX/BAG. Its theater scalar bootstrap also needs TEMPERATMD and
XShrapnel.MAP. `RA2_DIR` supplies the existing physical Water01 TMP owner; when
unset it defaults to the configured executable's parent. No file extraction or
map loading is implied by this generator.

## Measured chain

`building_death_anims.grapple_inputs` and `grapple_fixture` create actual stock
SQD and hostile DEST through their selected physical readers, constructors,
water Recalc and Unlimbo. Source ObjectLimbo then CanInfect/AttachTo run, with
living actors and reciprocal links. The admitted direct encounter excludes
the earlier FireAt/Bullet/LimboLaunch producer and full House/scenario startup.

The same VM then executes original Scenario defaults at 6838D3..6839BD, the normal
Lighting reader at 68A817..68A979 and Level store at 68A984..68A98A through the existing
`tmp_clear_render.profile` owner. No authored Lighting keys are supplied.
Options detail 2 and the existing six Cell relight (483E30) arguments are declared inputs;
whole original Cell relighting produces each level-zero Cell's signed +10A.
Neither a wanted 950 nor any Cell/Anim light or depth field is assigned.

Only the first whole Parasite update (6297F0) visit follows. It constructs physical SQDG,
passes the owner-change guard, calls SetOwner (424B50) and the source getter (705D70), and copies
the signed Cell +10A value at 629DDE into **Anim +FC at 629DE5**. The corpus observes
constructor +100, type +348 and the post-attachment +100 independently. It also
distinguishes actual instance +196 from type +35C (`ShouldUseCellDrawer=`).
The type flag alone does not select the instance's DrawIt branch.

The stable consumer fields are:

- `normal_profile`: actual six native Lighting units, matching
  `ScenarioLightProfileUnits`' field names.
- `cell_light` and `cell_controls`: actual signed Cell+10A plus complete
  before/after 104..10E scalar records for the source/victim cells.
- `constructor.arguments` / `.after`: original SQDG constructor inputs and
  returned fields, including separate `z_adjust` and `light_intensity_fc`.
- `held_anim`: actual retained fields after the whole 6297F0 call, with `z_adjust`,
  `type_z_adjust`, `light_intensity_fc`, instance `use_cell_drawer`, separate
  `type_should_use_cell_drawer`, owner identity and frame/runtime.
- `original_light_read` / `original_light_write`: original instruction,
  destination offset/width and observed old/new values.
- `draw_entry`: original DrawIt (422CA0)'s actual arguments at Surface (4AED70)
  entry, including depth, gradient, light, flags and physical image header.
  Surface/Convert identities are projected to null predicates, not pointers.

After the field measurement, the real held SQDG executes original DrawIt with
declared component point (80, 80) and clip (0, 0, 160, 160). Original 4237EA must
execute before the measurement stops at 4AED70 entry. The observed arguments include
Z = -2, vertical gradient 2, intensity 950 and flags 0x2E00; the actual instance
CellDrawer byte remains false despite the type flag being true. These are
call arguments, with no claim about a completed draw or resulting pixels.

## Explicit boundaries

The inherited Construction fixture's 705D70 sink is removed only for this
selected whole 6297F0 call. Original getter instructions run and return their actual
null, leaving Anim +D4 null. The fixture has no physical House ColorScheme
closure. This does not certify a stock House Convert or copied-light RGB.
Other inherited platform/presentation sinks remain declared by the setup owner.

The original call frame remains pending at Surface entry; Surface instructions
and return do not execute. The measured Surface and Convert receivers are
null. No palette/cache is initialized or replaced to make the component pass.
No DrawIfVisible/projection admission, raster, full Display traversal, later
relighting, other actor/Anim AI or complete gameplay scene executes. Nonzero
Cell light makes the FC-versus-100 field distinction discriminating; it does
not establish arbitrary current-cell lighting history or frozen-light RGB.
Full Surface completion needs a separate coherent native palette/renderer
closure. Renderer material compatibility for remapped Anims remains a separate
concern.

The historical [`parasite_grapple_rng`](building_death_anims_joined.md#squid-grapple-numeric-component)
corpus retains its original zero-light component. Its `z_adjust` snapshot reads
+100 only, so it cannot settle this copied-light field or pixels. This additive
control does not rewrite that history or strengthen its old coverage.
