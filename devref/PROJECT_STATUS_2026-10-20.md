## 1. 项目定位

- **是什么**：红色警戒 2：尤复的征途（RA2:YR）引擎的 Rust 重写，做**确定性强一致（lockstep）仿真内核**，目标无头跑 **20k 单位 / 30 家**对战。
- **双 crate**：
  - `vera20k-core`（`src/sim` 等）—— 确定性仿真 lib，绝不依赖渲染/UI/音频/网络/客户端。
  - `vera20k`（`src/{app,render,ui,audio,net}` 等）—— 客户端：渲染、UI、音频、网络、应用整合。
- **架构红线（AGENTS.md 权威契约）**：
  - `sim/` 永不依赖 `render/ui/audio/net/app`；`net/` 可依赖 `sim`（`architecture_guards.rs` 编译期强制）。
  - **research 不授权实现**；**不发明 offset / identity / behavior**。
  - 三层证据标准：Native established（native 取证坐实）→ Rust regression tested（回归测试）→ Parity demonstrated（与原版 parity 演示）。

## 5. native 取证与 lockstep 接入状态

### 5.1 证据级别

- 取证对象：`EventClass::Execute @ 0x4C6CB0` 的 46-opcode 分发表（`dec eax` 序言，0x01..0x2e 合法）。
- **retail + Steam 双证一致**：retail `E:/Ra2Game412/gamemd.exe`（白名单 `NATIVE_SHA256`），Steam `红警2重聚未来/Reunion`；**1,646 指令 + 46 switch 目标字节级 0 差异，同一 VA `0x4C6CB0`**。
- 局限：双证只证明两段 native 代码字节相同；**语义（对应哪个 VERA `Command` 变体）仍需 Ghidra 反编译 + dynamic trace 坐实**（虚表/递归类 handler 静态不可解析）。

### 5.2 已命名级坐实 + 已接入 sim 的 opcode

| opcode        | native 语义                                                    | VERA 接入                   | 取证证据                                                                     |
| ------------- | ------------------------------------------------------------ | ------------------------- | ------------------------------------------------------------------------ |

| `0x04`        | MegaMission（order 容器：Move/Attack/Guard/Enter/Hold/Harvest 等） | ✅ `MegaMission`           | 分支体 `0x4c6e72` 等                                                         |

## 7. 优先级总览（建议推进顺序）

- **P0（阻塞对战 / 确定性 / 正确性）**：
  1. `0x0c/0x22` 的 1/7 ↔ 0..=6 换算（让 SetGameSpeed 真正生效）
  2. `0x01/0x02` 残留守卫（`[obj+0x81]`/`[house+0x16c0]` 对应物）+ 21 项建筑列表
  3. 补齐战役/遭遇战**必需命令**的剩余 opcode 命名+接入
  4. **客户端端到端跑通一局**（仿真→渲染→输入闭环，当前未演示）
  5. 性能达实时（当前 0.14–0.25x）
- **P1（接近原版 parity + 联机可用）**：AI、触发脚本、超武、天气、寄生/心灵/伪装/间谍/工程师、网络完整（重连/观战/回放/反作弊）、渲染 parity、资源完整、CI 门禁。
- **P2（完整内容 / 打磨）**：全单位类型/武器/地形效果、pixel parity、音频完整、UI 打磨、mod 支持、跨平台、发布。

## 8. 风险与开放问题

- 取证仍依赖 Ghidra / dynamic trace 对**虚表 / 递归类** handler 坐实语义；形态学证据可定性（是 toggle 对、是改速）但**不能单独命名**。
- 性能与确定性存在**张力**：并行 / 向量化不能破坏 lockstep hash。
- **仿真内核强 ≠ 可玩**：客户端端到端尚未系统演示，是最大的"最后一公里"风险。
- 每次追加 `Command` 变体或快照字段须同步 bump `SNAPSHOT_VERSION` 并扩展版本标记测试（§4 已踩过一次回归）。
