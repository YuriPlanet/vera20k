# Switch 构建产物

所有 Switch 发布包只交付程序和安装元数据。禁止把零售游戏的 MIX、INI、CSF、地图、音频、视频、字幕或其他原始资源放进 NSP、NRO 或随包分发。玩家从自己的安装目录手动复制资源到 SD 卡的 `/game/`。构建不读取零售资源，交付前校验 Program NCA 仅含 ExeFS。

构建新版本时，先在交付目录核对新 NSP 的版本、Title ID 和 SHA‑256。校验通过后，从本次交付的 `dist` 删除同一发行版、同一 Title ID 的所有较旧 NSP 及各自的 `.sha256` 文件，只交付最新版。构建或校验失败时保留已有包。
