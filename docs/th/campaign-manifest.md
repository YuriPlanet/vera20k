# ชุดแคมเปญ

[English](../campaign-manifest.md) · [简体中文](../zh-CN/campaign-manifest.md) · [Deutsch](../de/campaign-manifest.md) · [العربية](../ar/campaign-manifest.md) · [Русский](../ru/campaign-manifest.md) · [Svenska](../sv/campaign-manifest.md) · **ไทย** · [Türkçe](../tr/campaign-manifest.md)

ไฟล์ `campaigns/<series>/campaign.ini` ระบุแผนที่ของแต่ละด่านในชุดแคมเปญ ในไฟล์เดียวกันยังระบุกฎ บทบาท เส้นทาง และสถานะที่จะส่งต่อไปยังด่านถัดไปได้ เริ่มจากแผนที่เดียวก่อน

ใช้ `asset campaign-check` เพื่อตรวจด่านโดยไม่ต้องเปิดห้อง หากจะเล่น ให้เปิดห้องสำหรับคนเดียวหรือจัดบทบาทให้ผู้เล่นหลายคน การเล่นผ่านอินเทอร์เน็ตต้องใช้ล็อบบี้ที่รองรับห้องแคมเปญ เมนู **แคมเปญ** ปกติใช้รายการจาก `battlemd.ini` ของเกม

[คู่มือคีย์](campaign-manifest-keys.md) ระบุค่าที่รับ ค่าเริ่มต้น และจังหวะที่ใช้ของแต่ละส่วน

## เริ่มจากด่านเดียว

บันทึก `campaign.ini` เป็น UTF‑8 ไว้ใน `campaigns/broken-line/` แล้ววางแผนที่ไว้ที่ `maps/opening.map` ภายในโฟลเดอร์ชุดแคมเปญ ไฟล์รายการมีขนาดได้ไม่เกิน 64 KiB ระบุพาธแผนที่จากโฟลเดอร์ชุดและใช้เครื่องหมาย `/`

```ini
[Stage Opening]
Map=maps/opening.map
```

ด่านที่ไม่มีบทบาทใช้ฝ่ายใน `[Basic] Player` และรับผู้เล่นหนึ่งคน

## ตรวจด่านโดยไม่เปิดห้อง

```text
asset campaign-check campaigns/broken-line/campaign.ini Opening 120 --ra2-dir "/path/to/Yuri's Revenge"
```

ระบุ ID ด่านและจำนวนเฟรมที่มากกว่าศูนย์ เครื่องมือจะรันด่าน สร้างใหม่จากการเล่นย้อนหลังเพื่อวินิจฉัย และเทียบสถานะทุกเฟรม เมื่อไฟล์รายการมีข้อผิดพลาด เครื่องมือจะแจ้งไฟล์ ส่วน คีย์ บรรทัด และวิธีแก้ หากไฟล์ในห้องไม่ตรงกัน ให้ตรวจไฟล์ INI ที่แผนที่เรียกใช้ด้วย

## เพิ่มบทบาท

หากเพิ่มบทบาท ให้ใช้ชื่อฝ่ายจากรายการ `[Houses]` ในแผนที่

```ini
[Roles Opening]
Lead=Americans
Support=Americans

[Grants Opening]
Lead.Russians=FullControl
Support.Russians=UnitsOnly
```

`Lead` และ `Support` ควบคุม `Americans` ร่วมกัน `FullControl` อนุญาตคำสั่งที่ต้องควบคุม `Russians` เต็มรูปแบบ ส่วน `UnitsOnly` อนุญาตคำสั่งยุทธวิธี กำหนดจำนวนผู้เล่นด้วย `MinPlayers` และ `MaxPlayers` ใน `[Routes Opening]` เขียน `Coast=Finale` เพื่อเชื่อมกับด่านที่ประกาศไว้ และใช้ `[CarryOver Opening]` เลือกข้อมูลที่จะส่งต่อ

## ติดตั้งและเปิดห้อง

วางโฟลเดอร์ชุดแคมเปญไว้ใต้ `campaigns/<series>/` ในโฟลเดอร์เกมหรือม็อดที่กำลังใช้ ผู้เล่นทุกคนต้องใช้บิลด์เกม กฎ และไฟล์แคมเปญชุดเดียวกัน เมื่อคัดลอกให้คงโครงสร้างโฟลเดอร์และนำไฟล์ INI ทุกไฟล์ที่แผนที่เรียกใช้ไปด้วย

1. สร้างห้อง LAN แล้วเลือกชื่อแคมเปญในรายการโหมด ใช้ **หลายผู้เล่นแบบมาตรฐาน** เพื่อกลับไปยังโหมดปกติ
2. เลือกด่านและระดับความยาก ถ้าด่านมีบทบาท ให้กำหนดหนึ่งบทบาทต่อผู้เล่นในคอลัมน์ **บทบาท** สองบทบาทสามารถควบคุมฝ่ายเดียวกันได้
3. เริ่มเมื่อผู้เล่นพร้อมครบ หากเข้าเล่นไม่ได้ ให้ตรวจไฟล์แคมเปญ บทบาท และจำนวนผู้เล่นที่ด่านรองรับ

ห้องผ่านอินเทอร์เน็ตต้องใช้ล็อบบี้ WOL ที่ประกาศ `campaign_rooms` และส่งต่อข้อมูลแคมเปญตอนเริ่มเกมและตอนเข้าชม หากล็อบบี้แจ้งว่าไม่รองรับ ให้ใช้ LAN ผู้ที่เข้าชมผ่านโหมดรับชมไม่ใช้ช่องบทบาทและไม่ลงคะแนน ก่อนเริ่ม ให้คืนช่องผู้ชมแบบปกติในห้องให้ว่าง

เกมจะรอให้ผู้เล่นถึงจุดเดียวกันระหว่างฉากคั่น เมื่อจบด่าน **เส้นทางอื่น** จะเปลี่ยนปลายทางที่แสดง กด **ดำเนินการต่อ** เพื่อลงคะแนนให้ปลายทางนั้น หรือ **ลองอีกครั้ง** เพื่อเริ่มด่านเดิมจากสถานะตอนเข้าด่าน ผู้เล่นต้องเลือกตรงกันจึงจะไปต่อได้
