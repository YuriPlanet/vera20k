# Personal gameplay rules (retired)

VERA20k used to read your own rule changes from `VERARULES.INI` beside `VERA.INI`. It no
longer does: make a mod instead. In the game, open **Options**, press **Mods**, then
**New Mod**, and change the new mod's `rulesmd.ini` ([Start a new mod](modding.md#start-a-new-mod)).

If your `VERARULES.INI` still holds changes, the game says so when it starts. Copy the
sections you changed into the mod's `rulesmd.ini`, then delete `VERARULES.INI`. The game
removes the file by itself when it is still the unchanged one it made.

Terrain Deformation and the Superweapon Limit are in the skirmish screen's Game Options.
