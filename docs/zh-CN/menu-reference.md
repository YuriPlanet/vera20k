# 菜单清单

**简体中文** · [English](../menu-reference.md)

这份清单列出玩家在游戏外和游戏内能点开、能设置的全部页面和菜单，根据源代码整理。代码与本文不一致时，以代码为准，并在同一次改动中修正本文。

**说明**

- 原版标签（`GUI:`、`STT:`、`TXT_` 开头的键）来自玩家游戏里的 `ra2md.csf`，仓库的 `src/i18n/vera20k.zh-CN.ini` 没有翻译它们。本文写的是通行中文译名。VERA 新增标签的中文以 `vera20k.zh-CN.ini` 为准。
- 【】里是存储位置。没有特别注明文件的 `[Section] Key` 都存在 VERA.INI 里。
- “仅本次”表示只存在内存里，重启游戏后恢复默认。

“战场高刷新率”默认关闭。可在显示页开启，也可在 `VERA.INI` 的 `[VERA]` 节中设置 `HighRefreshRateInBattle=yes`。无论垂直同步是否开启，只要绘制速度足够快，战场帧率就能达到显示器的刷新率。单位移动会更流畅，但显卡负载可能增加。

在 Windows 上，显示页的“图形 API”列表或 `VERA.INI` 中 `[VERA]` 节的 `GraphicsAPI=` 决定下次启动使用的渲染器：`opengl` 以 OpenGL 兼容模式启动，`vulkan` 或 `dx12` 只请求该 API。如果指定的 API 无法启动，游戏会弹窗说明，并改用另一个 API 启动，同时跳过此前启动失败过的 API。默认值 `auto` 让游戏自动选择。如果 Vulkan 或 DirectX 12 在启动时卡住或丢失图形设备，下次自动启动时游戏会尝试另一个 API，并在与 `VERA.INI` 同目录的 `GraphicsLostAtStart.txt` 中记录失败原因。如果两个 API 都找不到硬件显卡，游戏会尝试 OpenGL。环境变量 `WGPU_BACKEND` 优先于上述设置。上面的语言列表会写入 `[VERA]` 节的 `Language=`，也可以手动修改。

## 三、玩家进不去的旧页面

下面这些原版页面只有诊断截图模式（`native_shell_ui`）能打开，玩家实际进不去，所以没有列入上面的清单：

- WOL 欢迎页、旧登录页、我的信息、好友列表、地区选择页
- 旧大厅里的战队、锦标赛、新闻、私信按钮和频道列表
- 原版局域网 / 在线房间页
- WOL 选项里除“播放音乐”以外的 8 个原版勾选项

## 四、已知问题

修复其中某一项后，把它从这里删掉。

**同一个设置有好几个入口**

- 三个音量出现在 4 处：选项的音频分页、对局内的游戏控制页、声音页、WOL 选项里的声音选项。
- 滚动速度、目标线、显示隐藏物体、工具提示，在游戏控制页和选项分页各出现一次。
- 键盘页在对局内有 3 个入口。
- 全屏、性能统计、语言既在前端 Esc 菜单里，也在选项里。
- 在线对局里有两个“游戏速度”滑块，生效方式和范围不一样。

**同一套规则存了三份**

- 遭遇战、局域网房间、在线房间各存一份短局、箱子、资金等规则：分别在 `[Skirmish]`、`[LAN]`、`[WonlinePref]`。
- 房间里新增的禁用国家、桥梁、结盟，以及超级武器上限、地形变形、建筑生产队列，在房间里改了都不保存。
- 房间名、排位赛、大厅观战、玩家上限，重启游戏后全部恢复默认。

**改了不保存，或显示和实际状态不一致**

- 对局内声音页的改动不会立即写入 VERA.INI，要等以后某次整体保存。
- 用 Ctrl+Alt+L 锁定鼠标后，选项里的勾选框不会跟着变。
- 在线大厅的“观战”勾选，必须再点 WOL 选项的“确定”才保存。
- 从选项进入键盘页再返回，之前改的选项不会写入文件。

**没有效果，或开发者功能暴露给了玩家**

- 对局内仍可修改 Ares、跳过片头、原版 YR 风格、高清地图预览、平滑在线菜单，但在对局里不生效。
- 难度在对局中一直是灰的。
- 指挥官片段只在遭遇战有用，但局域网的对局菜单里也会显示。
- 性能统计、显示字符串键、跳过片头偏开发者用途，却放在玩家菜单里。
- 主菜单的 4 个隐藏输入码（PENGO、THETEAM、HIRES、TOGGLE）输入后会响一声，但实际没有效果。

**行为不一致**

- 前端 Esc 菜单的“退出游戏”不再确认，主菜单的“退出游戏”会先确认。
- 对局菜单的标题“游戏选项”和选项列里的“游戏选项”分页同名，但是两个不同的页面。
- Esc 只能打开对局菜单，不能关闭；在键盘页按 Esc 会直接丢掉还没保存的按键分配。

**缺功能，或用了也没用**

- 快速匹配没有任何偏好设置；能设置偏好的“我的信息”页现在进不去。
