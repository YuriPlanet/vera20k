### Systemic patterns
1. **Code that exists only for tests** (TESTONLY 41). Mechanisms were ported and pinned but never wired in: the tactical_compat spark consumer, the building_light CPU path, the native_z CPU mirrors of WGSL, the sidebar_text fade and the vxl occupied-column shadow. Their tests check code no player runs.
2. **Tests that restate the implementation** (MIRROR 62). Examples: copied tables (`compiled_event_rows_match_gamemd`), consts compared with themselves, derived Hash/Eq/Default checks, and test-local re-implementations of production branches. Two of those re-implement production outright: shell_paint `fit_emit`/`native_emit` and pixel_fx "Mimic the function's branch directly". There is also a shader source grep (`draw_state::gsi_13_09_*`).
3. **Duplicated helpers with duplicated tests.** Instances: asset_tools per-verb helper copies, `sanitiser_agrees_with_verb_render` (a test whose only job is keeping the copies in sync), `archive_basename` ×2, `label_text` ×2, `decrement_numeric_suffix` ×2 (overlay_atlas/bridge_atlas), and verb_art re-implementing the production cameo resolver. The render atlases also contain five separate shelf packers: tile_atlas `shelf_pack`, sidebar_cameo_atlas `shelf_pack`, sprite_atlas and unit_atlas `simulate_shelf_height`, and atlas_growth. These are refactor leads, not deletions.

### Tests that look WRONG
- `render/bridge_atlas.rs::shadow_darken_is_lighter_than_the_native_encoded_halve` (H). Its own comment says "Recorded DRIFT, not a parity assertion". It pins a non-native shadow that is about 44% too light, using sRGB math computed inside the test. It should become a one-line residual.
- `render/sidebar_cameo_atlas.rs::test_legacy_cameo_fallbacks_start_after_declared_candidates` (M). It pins "Repo-only fallback guesses … needs verification", which is invented behaviour.
- `render/overlay_atlas.rs::out_of_range_frames_still_collapse_to_zero`, `test_decrement_numeric_suffix_is_local_fallback` (L). Both pin VERA-internal guards and aliasing that gamemd does not have. Keep them only if they are recorded as residuals.
- `assets/pcx_file.rs::rgba_color_key_uses_rgb_not_palette_index` and `direct_rgb_color_key_applies_after_rgb_conversion` (flagged TESTONLY). They test a `#[cfg(test)]` exact-RGB color key that contradicts the native packed-RGB565 key in native_surface_format.rs (`apply_packed_color_key_rgba8`, 0x006153E0).

### Covered only by ignored e2e (not a basis for deletion)
- `native_z` CPU `sprite_row_z` versus the production zsprite/zdepth shaders. The only production check against rows.json is the ignored `terrain_draw_gpu_tests` "original clipped row fixture through the production owner". `original_extended_row_walk_matches_all_clipped_fixture_rows` is the only default-suite check, and it runs on a CPU copy. The owner must decide whether to keep that second implementation.
- `draw_state::gsi_13_09_zdepth_shader_*`: its comment defers to the ignored TMP/SHP/VXL GPU tests.
- `sidebar_text::native_radar_outline_color_uses_encoded_batch_tint_contract`: the shader readback lives in ignored `sidebar_gpu_tests`. Keep it.

### Default-suite tests that pass vacuously without retail data (25)
These include all of `mix_tests.rs` (13), `mix_diag_tests.rs` (3), `vxl_raster::jumpjet_tilt_draw_matrix_matches_native` (returns early unless RA2_DIR matches the retail sine table), `unit_atlas_tests::retail_vehicles_load_their_native_voxel_models`, `sprite_atlas_projectile_tests::retail_projectile_reader_*` and `shell_paint::fit_right_anchored_pins_real_sdbtnanm_canvas_width`.
