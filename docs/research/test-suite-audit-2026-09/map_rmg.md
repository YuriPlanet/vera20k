# Test audit: src/map/** (map proper + map/rmg)

Scanned: 909 `#[test]` (9 `#[ignore]`) across 85 files. Static reading only; no cargo.
Format: `path::test` | CATEGORY | evidence | confidence | action

## 0. Key finding: there is NO end-to-end native RMG golden

- `tools/rmg_oracle/` holds only `vectors/rng.json` (5 seeds x 16 draws) and `vectors/x87.json` (16 Gaussian calls). No whole-map byte comparison, no generated-map hash, no native map capture exists anywhere in the repo.
- The only default-suite whole-map tests are `src/map/rmg/build.rs` matrix tests (`dialog_reachable_matrix_generates`, `sed_only_matrix_generates`, `matrix_generation_is_deterministic`, `accessibility_moves_island_maps_and_leaves_the_others_alone`, `island_passes_reshape_only_the_island_map_types`). Their own header (build.rs:652-660) says: "REGRESSION RATCHET, never parity evidence ... synthetic 1x1 tile block ... morphable always false, cliff ranges None, six TileIds -1". They assert only: cells emitted, some tile != -1, rocks == 0 off-temperate, determinism.
- `src/app/random_map_lifecycle_tests.rs:113 gsi_04_12_random_map_ui_to_sed_launch_lifecycle_converges` is `#[ignore]` (RA2_DIR).
- Consequence: phase-level RMG tests can NOT be removed on E2E grounds. A regression in carve/bridge_deck/shore/lake geometry, tile ids or draw counts would not fail any default whole-map test. Only determinism tests and a few gate tests are actually subsumed by the matrix.
- Phase tests that localize and must stay (the only defence against draw-stream drift): `carve::a_level_run_takes_no_draw_and_a_sloped_one_takes_exactly_one`, `carve::a_refused_shape_falls_through_and_still_spends_its_draws`, `carve_driver::a_failed_roll_costs_one_draw_and_a_passed_roll_costs_two`, `carve_driver::flood_branch_visits_exact_qualified_ordered_slot_pairs_in_order`, `bridge_deck::every_rejection_costs_exactly_one_draw`, `bridge_deck::production_placer_exhausts_exactly_200_attempts_at_span_15`, `bridge_deck::four_end_coin_and_stamp_matrix_matches_native_production_owner`, `water::carved_water_types_consume_no_draws_at_zero_water`, `tech_buildings::type_draw_advances_the_stream_even_when_nothing_places`, `trees::zero_max_trees_is_a_no_op`, `lake::a_spent_quota_stops_the_next_lake_before_it_draws`, `build::the_coin_consumes_exactly_one_draw`, `grid::scan_order_matches_the_native_state_machine`, `rng::*_golden_vectors`, `x87::gaussian_matches_golden_vectors`, `description::fresh_seed_descriptions_match_original_reader_vectors`.
- Recommendation (tooling): a native whole-map golden (Unicorn-driven MapSeedClass run for a handful of seeds, hashed per stage) would be the one test that could justify retiring intermediate-structure phase tests; today it does not exist.
