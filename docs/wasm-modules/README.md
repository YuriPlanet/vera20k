# Wasm modules / Wasm 模块

Mods and maps can ship a simulation module (`rules.wasm`) and a client module (`ui.wasm`). The design is [RFC 0001](../rfcs/0001-wasm-extension-modules.md), with the [API appendix](../rfcs/0001-wasm-extension-modules-api.md).

Mod 和地图可以带一个模拟模块（`rules.wasm`）和一个客户端模块（`ui.wasm`）。设计见 [RFC 0001](../rfcs/0001-wasm-extension-modules.zh-CN.md)，接口细节见 [API 附录](../rfcs/0001-wasm-extension-modules-api.zh-CN.md)。
