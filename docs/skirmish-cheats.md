# Skirmish cheat codes

In **Skirmish → Game Options**, tick **Allow cheat codes**. During the match,
press **/** to open the command line. The slash is already there. Type the rest
of the command and press **Enter** to run it, or **Esc** to cancel.

| Command | Effect |
| --- | --- |
| `/money 10000` | Adds 10,000 credits to your current balance. |
| `/spysat` | Reveals the map for your house once. A later shroud reset can hide terrain again. |
| `/rhino 200` | Places up to 200 Rhino Tanks near your base. |
| `/spawn MTNK 25` | Places up to 25 Grizzly Tanks. Use a ground vehicle ID from the active rules, including a mod’s vehicles. |
| `/help` | Lists the commands. |

Vehicle commands accept 1 to 1,000 per order and report how many fit on clear
ground. Each order belongs to your house, whichever side you play.
Cheat codes default off. The checkbox saves to `[VERA] SkirmishCheats=` in
`VERA.INI` and applies only to offline skirmishes. Replays play back the cheats
you used.
