# Ключи манифеста кампании

[English](../campaign-manifest-keys.md) · [简体中文](../zh-CN/campaign-manifest-keys.md) · [Deutsch](../de/campaign-manifest-keys.md) · [العربية](../ar/campaign-manifest-keys.md) · **Русский** · [Svenska](../sv/campaign-manifest-keys.md) · [ไทย](../th/campaign-manifest-keys.md) · [Türkçe](../tr/campaign-manifest-keys.md)

Вместо `<id>` подставьте идентификатор миссии. Логические ключи принимают `Yes`, `No`, `True`, `False`, `1` и `0`. В таблицах приведены значения по умолчанию для миссий из этого манифеста. Прочерк означает отсутствие ключа. Неиспользуемую необязательную строку уберите целиком. [Установка, примеры и проверка](campaign-manifest.md)

## `[Campaign]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `Title` | Текст | Каталог серии | Клиент показывает это название в списке режимов после чтения установленных серий. Пример `Title=Broken Line`. |
| `Title.<locale>` | Текст | `Title` | При составлении списка клиент выбирает название для текущего языка. Пример `Title.ru=Разорванная линия`. Затем ищет базовый язык и `Title`. |

## `[Stage <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `Map` | Относительный путь | Обязательно | При проверке комнаты и загрузке открывается файл из каталога серии. Пример `Map=maps/opening.map`. Итоговый путь должен оставаться внутри серии. |
| `MapSha256` | 64 шестнадцатеричных знака | — | При проверке карты SHA-256 её файла сверяется с этим значением. Игроки сравнивают свои карты и при отсутствии ключа. |
| `MinPlayers` | 1–128 | `1` | Перед стартом должно быть не меньше указанного числа игроков. Для миссии, где нужны обе роли, задайте `MinPlayers=2`. Зрители не учитываются. |
| `MaxPlayers` | 1–128 | Предел ролей и комнаты | При допуске игроков действует наименьшее из этого числа, числа ролей и вместимости комнаты. Миссия без списка ролей вмещает одного игрока. |
| `Title` | Текст | `ID` | Выбор миссии и экран итогов показывают это название. Пример `Title=Прорыв`. |
| `Title.<locale>` | Текст | `Title` | В выборе миссии и итогах это название берётся для языка интерфейса. Пример `Title.ru=Прорыв`. Поиск такой же, как у `[Campaign] Title.<locale>`. |

## `[Roles <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `RoleId=HouseId` | ID фракции на карте | `[Basic] Player` для одного игрока | При подготовке и старте роль привязывается к фракции из `[Houses]`. `Lead=Americans` и `Support=Americans` делят основную фракцию. Каждую роль занимает один игрок. |

## `[Grants <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `RoleId.HouseId` | `FullControl` / `UnitsOnly` | — | При запуске `FullControl` даёт роли тактические команды и команды полного управления другой фракцией. `UnitsOnly` даёт тактические команды. Пример `Lead.Russians=FullControl`. Команды для основной фракции применяются к своей фракции. |

## `[Routes <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `BranchId=StageId` | ID объявленной миссии | — | При чтении проверяется, что цель объявлена. `Coast=Finale` добавляет миссию `Finale` в выбор продолжения. `Retry` может указывать только на текущую миссию. Кнопка повтора использует состояние при входе и без этой строки. |

## `[CarryOver <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `Globals` | `Yes` / `No` | `No` | При продолжении сохраняются текущие глобальные переменные триггеров и восстанавливаются до первого кадра следующей карты. |
| `Countdown` | `Yes` / `No` | `No` | В конце миссии сохраняется оставшееся время. Задайте `Countdown=Yes` и укажите `[Basic] TimerInherit=Yes` на карте назначения. |
| `MapStage` | `Yes` / `No` | `No` | В конце сохраняется внутренний числовой этап карты. `MapStage=Yes` переносит его на следующую карту. ID миссии берётся из маршрута. |
| `House.<id>` | `Credits` / `Difficulty` / `Credits,Difficulty` | — | При подведении итогов сохраняются деньги, сложность или оба значения фракции. `House.Americans=Credits,Difficulty` требует `Americans` на обеих картах. Сумму определяют `CarryOverMoney` и `CarryOverCap` карты назначения. |

## `[Rules <id>]`

| Ключ | Значения | По умолчанию | Когда и как действует |
| --- | --- | --- | --- |
| `Bootstrap` | `Campaign` | `Campaign` | При старте создаются фракции, заданные картой. Явная запись `Bootstrap=Campaign`. |
| `AllowWinTags` | `RequireClear` / `Ignore` | `RequireClear` | При проверке победы `RequireClear` ждёт обнуления меток AllowWin. `Ignore` пропускает проверку счётчика. Таймер результата действует в обоих случаях. |
| `ComputerParanoid` | `Disabled` / `React` | `Disabled` | При выборе врага или пересмотре отношений `React` разрешает вход в Computer_Paranoid. Остальные проверки правил и фракций действуют. |
| `Crates` | `Keep` / `Skip` | `Keep` | При загрузке наложений `Keep` сохраняет расставленные ящики. `Skip` пропускает их. За появление ящиков по времени отвечает `UsesMatchCrates`. |
| `AiBase` | `RetainAuthoredNodes` / `ReplaceUnavailableNodes` | `RetainAuthoredNodes` | При работе ИИ с базой `RetainAuthoredNodes` сохраняет заданные позиции. `ReplaceUnavailableNodes` позволяет заменять недоступные позиции и места с повторными отказами. |
| `DoubleOwned` | `OwnerMask` / `AllCountries` | `OwnerMask` | При выборе завода `OwnerMask` использует обычную маску стран, а `AllCountries` расширяет её для типов с `DoubleOwned=Yes`. |
| `TeamCreationLimitScope` | `AllHouses` / `PerHouse` | `AllHouses` | При создании отряда `Max=` учитывает отряды всех фракций или только фракции-создателя. |
| `CountsPlayerControlAsHuman` | `No` | `No` | При старте игровые фракции задаются занятыми ролями. Это можно явно указать как `CountsPlayerControlAsHuman=No`. |
| `AllowsConstructionYardRedeploy` | `Yes` / `No` | `No` | При приказе свернуть стройплощадку включает путь сворачивания подходящей постройки. Параметры здания и опции игры проверяются. |
| `AllowsIdleObjectSleep` | `Yes` / `No` | `No` | При обновлении кадра разрешает усыплять подходящие бездействующие объекты с учётом триггеров и ремонта. |
| `AllowsOwnerlessTerrainLogic` | `Yes` / `No` | `Yes` | При обновлении местности включает бесхозные объекты, которые обычно исключает проверка идентичности. |
| `UsesCountryDifficultyBiases` | `Yes` / `No` | `No` | При назначении сложности учитывает модификаторы выбранной страны. |
| `SkipsLocalPlayerAuthoredBuildings` | `Yes` / `No` | `No` | Загрузчик зданий проверяет этот ключ только при локальном исполнении. В lockstep размещённые здания загружаются. Чтобы убрать здание, измените карту. |
| `UsesManagedAiBase` | `Yes` / `No` | `No` | В ходе игры включает для подходящих ИИ-фракций автоматическую стройку, выбор площадки и развёртывание. |
| `UsesAiEconomy` | `Yes` / `No` | `No` | При расчётах ИИ включает сетевые правила оплаты руды и разрешённой продажи зданий. |
| `RunsAiStrategy` | `Yes` / `No` | `No` | При обновлении стратегии включает периодический поиск противников и самостоятельные решения ИИ о строительстве. |
| `UsesHouseTeamRules` | `Yes` / `No` | `No` | При загрузке и запуске отрядов включает проверки триггеров по фракции. Сложность и TechLevel берутся в этой ветви по правилам фракции и отряда. |
| `UsesCampaignDiscovery` | `Yes` / `No` | `Yes` | При обзоре и выборе цели использует правила обнаружения кампании. Ветка обнаружения для одного клиента требует локального исполнения. |
| `UsesCampaignBaseDefense` | `Yes` / `No` | `Yes` | При атаке на базу применяет правила кампании к реакции атакованного объекта и подходящих защитников. |
| `UsesDirectedHunterSeekerTargeting` | `Yes` / `No` | `No` | При пуске охотника Ares позволяет ИИ использовать назначенного врага. Игрок может получать предпочтение непассивных целей, если это допускает `RandomOnly`. |
| `UsesMatchCrates` | `Yes` / `No` | `No` | В игре включает сетевой жизненный цикл ящиков, в том числе слоты по времени и проверки подбора. Автоматическое появление зависит от опции ящиков. |
| `UsesEliminationResults` | `Yes` / `No` | `No` | При подведении итогов определяет результат по выбыванию фракций и выполняет очистку. Значение по умолчанию оставляет результат за сценарными триггерами. |
| `UsesRoomOptions` | `Yes` / `No` | `No` | При создании сценария включает стартовые параметры комнаты для иммунитета сборщиков, роста и распространения руды. |
| `UsesCampaignDiplomacy` | `Yes` / `No` | `Yes` | При нажатии «Дипломатия» включает брифинг кампании. Ключ также включает правила кампании для пассивных и гражданских фракций при дипломатии. |
| `AllowsManualAlliances` | `Yes` / `No` | `No` | При команде заключения союза включает её обработку. Допуск зависит от правил союзов и полномочий игрока. |
| `ModMapAdditions` | `Yes` / `No` | `No` | Перед графической загрузкой применяет дополнения к карте из активного мода. У всех игроков должны совпадать файлы мода. Для локальной проверки внесите нужные параметры в карту. |
| `SharedAlliedVictory` | `Yes` / `No` | `No` | При lockstep-итогах по выбыванию подходящие выжившие союзники могут разделить победу. |
| `SkipsNetworkScoreDialog` | `Yes` / `No` | `No` | При вызове общего сетевого экрана очков пропускает его. У продолжения кампании свой экран итогов. |
| `ParanoidIgnoresAlliesAllowed` | `Yes` / `No` | `No` | При проверке союза в `ComputerParanoid=React` позволяет ИИ обойти `AlliesAllowed`. Команды игрока проверяются отдельно. |
| `NetworkDiplomacyBriefing` | `Yes` / `No` | `No` | При нажатии «Дипломатия» открывает брифинг и список полномочий ролей. Пример `NetworkDiplomacyBriefing=Yes` и текст в `[Basic] Briefing`. |
| `StartingHouseRoleAlliances` | `Yes` / `No` | `No` | При старте из слотов объединяет стартовые фракции с одинаковой классификацией игрока или ИИ. Для фракций, заданных картой, задайте союзы на карте. |
| `AresPsychicRevealExclusions` | `Yes` / `No` | `No` | При психическом раскрытии Ares в lockstep сохраняет три исключённые клетки, заданные относительно границ карты. |
| `DissolveUnfilledTeams` | `Yes` / `No` | `No` | При обновлении отрядов распускает пустой отряд, который ни разу не заполнился, после `DissolveUnfilledTeamDelay`. |
