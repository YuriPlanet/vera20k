# Серии кампаний

[English](../campaign-manifest.md) · [简体中文](../zh-CN/campaign-manifest.md) · [Deutsch](../de/campaign-manifest.md) · [العربية](../ar/campaign-manifest.md) · **Русский** · [Svenska](../sv/campaign-manifest.md) · [ไทย](../th/campaign-manifest.md) · [Türkçe](../tr/campaign-manifest.md)

В `campaigns/<серия>/campaign.ini` указывается карта каждой миссии. Там же можно задать правила, роли, маршруты и данные, которые перейдут в следующую миссию. Для начала достаточно одной карты.

Команда `asset campaign-check` проверяет миссию без комнаты. Для игры создайте комнату на одного человека или назначьте роли нескольким игрокам. Для игры через Интернет нужна поддержка кампаний на сервере лобби. Обычное меню **Кампания** использует список из `battlemd.ini`.

[Справочник ключей](campaign-manifest-keys.md) содержит допустимые значения, настройки по умолчанию и назначение каждого ключа.

## Начните с одной миссии

Сохраните `campaign.ini` в UTF‑8 в каталоге `campaigns/broken-line/`, а карту в его подкаталоге `maps/opening.map`. Максимальный размер манифеста составляет 64 КиБ. Указывайте путь относительно каталога серии, используя `/`.

```ini
[Stage Opening]
Map=maps/opening.map
```

Миссия без списка ролей использует фракцию из `[Basic] Player` и вмещает одного игрока.

## Как проверить миссию без комнаты

```text
asset campaign-check campaigns/broken-line/campaign.ini Opening 120 --ra2-dir "/path/to/Yuri's Revenge"
```

Укажите идентификатор миссии и положительное число кадров. Команда запускает миссию, заново строит её из диагностической записи и сравнивает состояние на каждом кадре. При ошибке манифеста выводятся файл, секция, ключ, строка и подсказка. Если файлы в комнате не совпадают, проверьте и подключаемые картой INI-файлы.

## Как добавить роли

Чтобы добавить роли, возьмите названия фракций из списка `[Houses]` на карте.

```ini
[Roles Opening]
Lead=Americans
Support=Americans

[Grants Opening]
Lead.Russians=FullControl
Support.Russians=UnitsOnly
```

`Lead` и `Support` делят фракцию `Americans`. Уровень `FullControl` также разрешает команды, требующие полного управления `Russians`. Уровень `UnitsOnly` даёт тактическое управление. Ограничения числа игроков задают `MinPlayers` и `MaxPlayers`. В `[Routes Opening]` строка `Coast=Finale` ведёт к объявленной миссии. В `[CarryOver Opening]` укажите, какие данные перенести.

## Установка и создание комнаты

Поместите папку серии в `campaigns/<серия>/` в каталоге игры или активного мода. У всех игроков должны совпадать сборка игры, правила и файлы кампании. Сохраните структуру каталогов и добавьте все INI-файлы, подключаемые картами.

1. Создайте комнату в локальной сети и выберите кампанию в списке режимов. **Обычная сетевая игра** возвращает стандартные режимы.
2. Выберите миссию и сложность. Если в миссии есть список ролей, назначьте каждому игроку отдельную роль в столбце **Роль**. Две роли могут управлять одной фракцией.
3. Запустите игру, когда все готовы. При отказе проверьте файлы кампании, роли и допустимое число игроков.

Для интернет-комнаты нужен сервер WOL с возможностью `campaign_rooms`. Он передаёт настройки кампании при запуске, в том числе тем, кто подключается для просмотра. Если сервер сообщает, что кампании недоступны, создайте комнату в локальной сети. Подключённые в режиме просмотра зрители не занимают роли. Перед запуском освободите обычные места наблюдателей в комнате.

Во время ролика игра ждёт, пока все игроки дойдут до одной точки. После миссии **Другой маршрут** меняет показанную цель. **Продолжить** отдаёт голос за эту цель, а **Повторить** заново запускает миссию с её начальным состоянием. Для перехода все игроки должны выбрать одно и то же. Зрители в голосовании не участвуют.
